# DraftMaster — техническое задание

## 1. Что это
DraftMaster — приложение для анализа драфтов Dota 2, подбора контрпиков и оценки синергии героев.

## 2. Для кого
- Игроки Dota 2.
- Новички, изучающие героев.
- Игроки, желающие улучшить понимание драфтов.

## 3. Основные функции
- Просмотр списка героев.
- Просмотр характеристик и ролей героев.
- Выбор героев противника.
- Подбор контрпиков.
- Анализ синергии союзных героев.
- Сохранение и просмотр драфтов.

## 4. Основные сущности
- User — пользователь приложения.
- Hero — герой Dota 2.
- Draft — сохранённый драфт.
- DraftPick — выбранный герой в конкретном драфте.

## 5. Технологический стек
- Python
- FastAPI
- SQLite
- SQLAlchemy
- OpenDota API
- Git / GitHub
